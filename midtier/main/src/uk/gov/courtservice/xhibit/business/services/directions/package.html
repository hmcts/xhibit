This package contains the classes concerned with the addition of a Directions for Case entity and event

Package Usage

The main entry points to this package are via the DirectionsWorkFlow class.

  • DirectionsWorkFlow - provide an instance of DirectionsHelper class by passing it the DirectionsValue via the saveDirections method.
  • DirectionsHelper - via the saveDirections method, then iterates through the elements of the DirectionsValue to create or update Directions for case and defendant entities. Use is made of the DirectionsForCaseMaintainer and DirForDefMaintainer classes to update and add directions. The class is also repsonsible for calling the DirectionsEventHelper class to handles the CourtLogCRUDValues set on the DirectionValue.
  • DirectionsEventHelper - via the orderAndCreateUpdateCourtLogEvents method, iterates through elements of the ArrayList of CourtLogCRUDValues. After ordering, court log entries created or existing entries are updated. The CourtLog entries are created by calling CourtLogController class methods.
