instructions for the installation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1)

The SQL script

  Xhibit_DB_Patch_8_6_0.sql 

should be run as the Oracle xhibit user to update the XHIBIT DB schema.

2)

The SQL script

  EXI_database_amendments.sql 

should be run as the Oracle Exiss user to update the Exiss DB schema.

3)

The SQL script

  CJIT_database_amendments.sql 

should be run as the Oracle CJIT user to update the CJIT DB schema.
