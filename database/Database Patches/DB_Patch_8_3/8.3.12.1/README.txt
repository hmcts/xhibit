installation instructions 
~~~~~~~~~~~~~~~~~~~~~~~~~


1)

The SQL script

    xhb_validation_pkg_h.sql 

should be run as the Oracle xhibit user to create the validation package header.

2)

The SQL script

    xhb_validation_pkg_b.sql  

should be run as the Oracle xhibit user to create the validation package body.

3)

The SQL script

  Xhibit_DB_Patch_8_3_12_1.sql 

should be run as the Oracle xhibit user to update the XHIBIT DB schema.

4) 
The SQL script 

     EXI_database_objects.sql

shouldbe run as the Oracle Exiss user to update some records in the Exiss database
