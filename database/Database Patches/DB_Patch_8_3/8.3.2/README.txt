installation instructions 
~~~~~~~~~~~~~~~~~~~~~~~~~

1)

The SQL script

  Xhibit_DB_Patch_8_3_2.sql 

should be run as the Oracle xhibit user to update the XHIBIT DB schema.

2)
The SQL script with the prefix of EXI, relates to sql that requires execution within the EXISS database, using the Oracle EXISS user to update the EXISS DB schema.
