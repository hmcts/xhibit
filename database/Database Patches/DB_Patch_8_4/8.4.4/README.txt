Installation instructions
~~~~~~~~~~~~~~~~~~~~~~~~~

1)

  If not already run, execute the database scripts for versions: 8.4.0; 8.4.1; 8.4.2; 8.4.3

2)

The SQL script

  Xhibit_DB_Patch_8_4_4.sql 

should be run as the Oracle xhibit user to update the XHIBIT DB schema.

3)
The SQL script

  Leo_Adv_Link_Trigger.sql 

should be run as the system Oracle user to update the XHIBIT DB schema.
