Installation instructions
~~~~~~~~~~~~~~~~~~~~~~~~~

1)

  If not already run, execute the database scripts for versions: 8.4.0; 8.4.1; 8.4.2; 8.4.3; 8.4.4;8.4.6

2)

The SQL script

  Xhibit_DB_Patch_8_4_7.sql 

should be run as the Oracle xhibit user to update the XHIBIT DB schema.

3)
The SQL script

  EXISS_DB_Patch_8_4_7.sql 

should be run as the exiss Oracle user to update the EXISS DB schema.

4)
The SQL script

  CJIT_DB_Patch_8_4_7.sql 

should be run as the cjit Oracle user to update the CJIT DB schema.
