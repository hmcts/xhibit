The CJSE scheama files are no longer stored in a directory with the version name in the directory name.  
The files are now stored in

  CJSE\cjse\*

To get the CJSE files for a particular CJSE release you will need to get the appropriate CVS branch.
Branches are named:

  CJSE_BRANCH_<version>

For example

  CJSE_BRANCH_V5_1
  CJSE_BRANCH_V5_2

To get the branch you would like to work on, right click on the cjse directory and choose

  CVS -> Update Special...

Ensure 'Get tag/branch/revision' and 'Clean copy - WARNING: this deletes your changes' are ticked.

Enter the branch tag you require into the field at the top of the dialog box.

Press OK.
