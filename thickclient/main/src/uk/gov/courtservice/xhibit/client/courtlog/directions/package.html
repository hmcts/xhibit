This package and it's children provide the functionality to add, change and delete court log events specific to directions and to view the resultant changes in the court log screen.

Package Structure

Excluding those items described below, there is no specific package structure supported since the majority of user generated court log events are defined in this, the main level.

  • uk.gov.courtservice.xhibit.client.courtlog.directions:
    Contains the components that support the majority of direction court log events. These in turn are grouped by name thus, files concerning one specific court log event share the same stem (see also Naming Convention below)
    • uk.gov.courtservice.xhibit.client.courtlog.directions.caze:
      Contains components that perform processing specific to directions for case court log events.
    • uk.gov.courtservice.xhibit.client.courtlog.directions.defendant:
      Contains components that perform processing specific to directions for defendant court log events.

Direction Event Types

The direction event types are split into defendant specific and case specific event types.

Event Types for Defendant

  • Identification (40704) - where the user is presented with 'Defendant Identified' and 'No reply' radio buttons for selection.
  • Arraignment (40705) - where the user is presented with 'Arraigned' and 'Not arraigned' radio buttons for selection.
  • Bail or Custody (40706) - where the user is presented with 'Remanded in custody', 'Bail as before' and 'Bail Varied' radio buttons for selection. A text area to record 'New conditions' also exists.
  • Certificate of Attendance (40707) - where the user is presented with 'Granted', 'Refused' and 'Not requested' radio buttons for selection.
  • Form B (40708) - where the user is presented with 'Filed' and 'To be filed' radio buttons for selection. A date combo also exists for date selection.
  • Long Adjournment (40708) - where the user is presented with a combo box for defendant selection, a checkbox to apply the event for all defendants on the case, a combo to select a adjourment option, a check box for 'PSR Required', radio buttons for 'Reserved to Judge' and 'Not Reserved' and a textbox for judge name. A button launches functionality to search for a judge.

Event Types for Case

  • P&D Form (40710) - where the user is presented with 'Form handed in' and 'Form NOT handed in' radio buttons for selection.
  • Trail Time (40711) - where the user is presented with a textbox for period entry and a combo box to select the unit of entry (days, weeks etc...)
  • Directions (40712) - where the user is presented with a textbox for directions entry.
  • Freetext (40711) - where the user is presented with a text area forthe freetext, log date and log time screen components. A number of court log events are supported by this mechanism

Direction Specific Structure

Key components on the Directions screen extend the class DirectionsParentPanel. This class extends XPanel therefore implementing the life cycle methods in XPanel. DirectionsParentPanel overides these lifecycle methods and in each of these methods it recursively calls the same method on all the XPanel components the panel contains.

This panel is the parent panel of the following panels:

  • DirecitonForDefendant
  • DirectionForCase
  • DirectionSingleEventPanel
  • DirectionDefendantSelector
  • Directions
