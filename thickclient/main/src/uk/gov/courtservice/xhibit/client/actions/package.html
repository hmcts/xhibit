This package and it's children provide the functionality to invoke process, panels and dialogs within the XHIBIT application in response to user input.

Adding New Actions

Court Log Events

The following files must be added or updated in order to make available a new court log event on the XHIBIT court log menu and toolbar:

  • config.bundles.CLSubstitution_client_en_GB.properties
  • config.bundles.XhibitActionResources_en_GB.properties
  • config.xml.CourtLogMenu.xml
  • images.<eventname>.gif
  • uk.gov.courtservice.xhibit.client.actions.XhibitActions.java
  • uk.gov.courtservice.xhibit.client.actions.XhibitActionBundle.java
  • uk.gov.courtservice.xhibit.client.actions.courtlog.<EventName>Action.java
